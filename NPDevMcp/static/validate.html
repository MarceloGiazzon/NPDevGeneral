How an AI can use this page
  1. Navigate to /#model=<URL-encoded model JSON> (or #model64=<base64url>). The page validates by itself; the hash never reaches the server.
  2. Or open /?modelUrl=<https link to a raw model.json>: the browser fetches it and validates.
  3. Or type/paste the JSON into the box and press Validate; or drop a .json file on it.
  4. Read the result from: the console line starting with NPDEV_VALIDATION_RESULT; the <pre id="npdev-result"> text; <script id="npdev-result-json">; the tab title; document.body.dataset.npdevStatus; or window.npdevLastResult.
  5. From JavaScript on this origin: fetch('/api/validate', {method:'POST', body: JSON.stringify(model)}). Fix the errors and repeat until status is passed or warning.
