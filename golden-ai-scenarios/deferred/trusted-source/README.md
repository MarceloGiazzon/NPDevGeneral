# Deferred Trusted-Source Scenarios

CP3 uses the locked Path B decision for trusted-source scope. These scenarios are preserved exactly as deferred evidence inputs, but they are excluded from active golden scenario coherence, mapping policy, schema validation, and AI beta gate runs.

Trusted-source scenarios may return to active scope only after a later approved checkpoint proves manifest locking, Java source and bytecode restrictions, generated runtime integration, browser and CSP behavior, role and tenant enforcement, and path traversal rejection from fresh current evidence.
