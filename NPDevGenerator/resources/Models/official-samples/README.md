# Official Samples Category

This directory now holds the authoritative curated official sample models.

## What lives here

Each official sample is standardized as a maintained product asset with:

- `model.json`
- `config.json`
- `manifest.json`
- `README.md`
- example input payloads under `input`
- expected endpoint notes
- expected diagnostics notes
